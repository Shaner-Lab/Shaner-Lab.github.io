Multi-condition comparison matrix

How the matrix is built

Cartesian product of selected illuminations × dichroics × emission filters. Empty dichroic or filter adds a no dichroic or open channel slice. Each cell uses the single-condition engine, then normalization for displayed %. Default mode: global. Rel. power defaults to 1.0 per lamp. Raw SearchLight lights are omitted until composed with an excitation filter (Import → Manual optics).

Multi-condition comparison requires grouped fluorophore entries. Import fluorophores from FPbase, Dyes, SearchLight, or load the sample bundle; then configure illumination, dichroic, and emission-filter conditions for comparison.
